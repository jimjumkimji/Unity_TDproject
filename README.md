This project is a Tower Defense (TD) game developed using Unity, where players strategically place towers to defend their base from waves of incoming enemies. The gameplay focuses on planning and resource management, allowing players to build and upgrade towers, earn in-game currency, and survive increasingly difficult enemy waves. The system is designed to challenge players’ strategic thinking while maintaining engaging and dynamic gameplay.

On the backend side, the system is built with Node.js and Express, connected to a MongoDB database using Mongoose for data modeling. Player authentication is handled securely using JSON Web Tokens (JWT), while passwords are encrypted with bcrypt to ensure data protection. Additional tools such as dotenv are used for environment variable management, and cors is configured to allow communication between the Unity client and the server.

The Unity game client communicates with the backend through HTTP API requests to manage user accounts and store player data such as scores, levels, and progress. This enables persistent online data storage and provides a foundation for future expansions, such as leaderboards, ranking systems, or cloud save functionality. Overall, this project demonstrates the integration of Unity game development with a modern backend architecture to create a secure and scalable online game system.
